Admin · reusable AI marking

Marking rules

Create and check a reusable marking plan. Any linked revision subject can give the same clear instructions to its AI helper.

Choose a starting point

How to write rules

Each line has one instruction. The AI receives both this readable text and a checked structured version.

SCHEME My subject
COMMAND Explain
MARKS 2
AWARD 1 accurate relevant knowledge
AWARD 1 a clear linked explanation
REQUIRE answer the question directly
NEVER invent a quotation or source
FEEDBACK give one precise next step

COMMAND Evaluate
MARKS AUTO
BAND 9-12 balanced evaluation with a supported judgement
BAND 5-8 relevant arguments with some evaluation
BAND 1-4 limited points or description
  • COMMAND ALL applies to every question.
  • MARKS AUTO uses the marks on the question.
  • AWARD states a mark and its credit condition.
  • BAND states a score range and what that range looks like.
  • REQUIRE, NEVER and FEEDBACK guide the AI.

Ask another AI to make marking rules

Give the AI official mark-scheme links or your own checked rules. It should produce this small DSL, not a revision subject.

Create a reusable marking schema in the DSL below. This is separate from revision questions.

Board/course and year: [replace this]
Question instructions and marks: [for example Explain 2 marks; Evaluate 12 marks]
Official source links: [paste current syllabus and mark scheme links]
My custom requirements: [replace this]

Rules:
- Return one JSON object only with id, title, status, version, dsl, rules, references and sourceNotes.
- status must be "adaptable" for board-based guidance or "custom" for user rules.
- Never call the result an official mark scheme unless every descriptor was directly verified.
- DSL instructions: SCHEME, COMMAND, MARKS, AWARD, BAND, REQUIRE, NEVER, FEEDBACK.
- Use COMMAND ALL for shared rules and MARKS AUTO to use the question's own tariff.
- Preserve a source link and clearly say which details were not verified.
- The parsed rules array must mirror every DSL line.

Example:
SCHEME My marking plan
COMMAND Explain
MARKS 2
AWARD 1 accurate relevant knowledge
AWARD 1 a clear linked explanation
REQUIRE answer the exact question
NEVER invent an official mark
FEEDBACK give one precise next step
