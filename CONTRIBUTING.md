# Contributing

Thanks for helping. Everything you need is in the documentation:

1. [Getting started](docs/develop/getting-started.md): build it, run it and open a pull request.
2. [Subjects](docs/develop/subjects.md): add or edit questions, and the content rules for this public
   repository.
3. [Testing](docs/develop/testing.md): how to test code changes, and the checks to run before you push.

Rules for coding agents and maintainers (Definition of Done, hard stops, privacy) are in
[AGENTS.md](AGENTS.md).
